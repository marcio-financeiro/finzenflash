💾 Backup

Backup completo de todos os seus dados, pronto pra restaurar depois.

Diferente da "Exportar para análise com IA" (que seleciona/transforma os dados pra leitura por uma IA), isto é um dump fiel de todas as tabelas — contas, cartões, categorias, lançamentos, cartão, transferências, investimentos, patrimônio etc. — pensado pra restaurar o estado exato do app depois (troca de aparelho, ou desfazer um erro grave).

Fazer backup agora

Baixa um .json com tudo. Guarde num lugar seguro — tem seus dados financeiros em texto puro.

Restaurar de um backup

Escolha um .json gerado aqui. Nada é apagado — registros com o mesmo ID são atualizados, o resto é adicionado.

Confirmar restauração

Isso vai sobrescrever qualquer registro que já exista com o mesmo ID. Confira a data de geração do backup acima antes de continuar.
