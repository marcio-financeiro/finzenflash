💾 Backup

Backup completo de todos os seus dados (contas, cartões, categorias, lançamentos, investimentos etc.) em um único arquivo JSON — pra guardar num lugar seguro ou restaurar depois numa troca de aparelho. Isto é diferente da "Exportar para análise com IA": lá os dados são selecionados/transformados pra leitura por uma IA; aqui é um dump fiel, pensado pra restaurar.

Fazer backup agora
Baixa um arquivo .json com tudo. Guarde num lugar seguro — o arquivo tem seus dados financeiros em texto puro.
Restaurar de um backup
Escolha um arquivo .json gerado aqui. Nada é apagado — registros com o mesmo ID são atualizados, o resto é adicionado.
Confirmar restauração
Isso vai sobrescrever qualquer registro que já exista com o mesmo ID. Confira a data de geração do backup acima antes de continuar.
